# BAU Core Runner Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `bau` Python package and container image on Cere that, each night, reads BAU-labelled Plane items, runs one Claude Code session per item in a disposable Linux container, raises a PR per item, handles feedback on existing PRs, and writes `state.json`, all under the usage policy in the spec.

**Architecture:** Host-side Python (`bau-run`) owns every decision and every write to Plane and GitHub; the agent inside the container only edits code and pushes a branch. Pure-function policy and parsing modules are tested in isolation; the Plane and GitHub clients are tested against `httpx.MockTransport`; the session runner is tested against a fake `docker` script; the run loop is tested with in-memory fakes of all of them.

**Tech Stack:** Python 3.12, `httpx`, `PyJWT[crypto]`, `PyYAML`, `pytest`, `ruff`; Docker via Colima on Cere; `tinyproxy` as the egress allow-list; launchd for scheduling.

**Spec:** `docs/superpowers/specs/2026-10-14-bau-design.md` (currently `~/repos/nakomis/bau-spec/2026-10-14-bau-design.md`; Task 1 moves it).

## Global Constraints

- Repo `nakomis/bau`, **private**, CC0 licence, created with the `/create-repo` skill. Plane project `BAU`.
- British English everywhere, including commit messages. Commit messages carry no attribution lines and no "Generated with" lines (Martin's CLAUDE.md overrides the harness reminder).
- Always on a feature branch; every task's work lands by PR. The first PR is the scaffold.
- Python `>=3.12`. Runtime deps only `httpx>=0.27`, `PyJWT[crypto]>=2.9`, `PyYAML>=6`. Dev deps `pytest`, `pytest-cov`, `ruff`. Coverage floor 70% (`--cov-fail-under=70`).
- Host-side code runs on Cere as the `nakomis` user (Cere is an 8 GB M1 Mac mini with auto-login as `nakomis` and Colima as the Docker engine, per the home-infra `home-446-cere-playbook` branch; a second login session with its own Colima VM does not fit, so the container, not a second user, is the isolation boundary). All BAU files live under `/Users/nakomis/bau/`. Secrets live in the login keychain under service `bau`.
- Policy constants from the spec: pace margin 0.10; five-hour kill 0.80; wall-clock kill 60 minutes; no new sessions after 05:00 Europe/London; open-PR ceiling 50; fail-closed cap 2 sessions; CI-fix sessions per PR 1 per night, 3 in total; too-big thresholds 15 files or 400 changed lines.
- Models: default `claude-opus-5-5`; label `BAU-fable` selects `claude-fable-5-1`.
- Identities: owner GitHub login `nakomis`, owner Plane email `martin@nakomis.com`, worker Plane email `bau@nakomis.com`, worker GitHub login `nakomis-bau[bot]`.
- The agent container's egress allow-list is `api.github.com`, `github.com`, `objects.githubusercontent.com`, `api.anthropic.com`, `registry.npmjs.org`, `pypi.org`, `files.pythonhosted.org`. The agent never talks to Plane; only the host-side runner does.
- Bare repos are mounted read-only into containers at the **same absolute path** as on the host, because `--reference` clones record an absolute alternates path.
- Spike 1 (14 Oct 2026) confirmed the stream shape: `{"type":"rate_limit_event","rate_limit_info":{"status":"allowed|allowed_warning|rejected","unifiedWindows":{"five_hour":{"utilization":0.55,"resetsAt":1791994800},"seven_day":{"utilization":0.54,"resetsAt":1792418400}}}}`. The result line is `{"type":"result","subtype":"success","is_error":false,"result":"...","total_cost_usd":0.0027}`. `--bare` must not be used (it ignores the subscription login).

## Review Focus

1. A Plane item whose description is empty or whose `repo:` override names a repo not installed on the App: the runner must decline with a comment, not crash the night. Test in Task 12.
2. A `rate_limit_event` arriving with `unifiedWindows` missing one window: treat as telemetry missing (fail closed), never as 0% used. Test in Task 3.
3. The agent prints `BAU_TOO_BIG:` in the middle of its output and then carries on and opens a PR anyway: the runner must honour the diff thresholds independently and close the PR as too big. Test in Task 12.
4. A review thread where Martin's last comment is simply "Done, thanks" and the thread is unresolved: it is still pending, by design, and the worker replies and resolves it. Test in Task 7 that it is pending; the house prompt tells the agent to resolve such threads.
5. Two tickets in the same repo on the same night: the second checkout must not disturb the first's branch and both must fetch from the same bare clone. Test in Task 8.

```python
from __future__ import annotations

from dataclasses import dataclass
from datetime import time
from pathlib import Path

import yaml


@dataclass(frozen=True)
class KeychainRef:
    service: str
    account: str


@dataclass(frozen=True)
class Limits:
    open_pr_ceiling: int
    pace_margin: float
    five_hour_kill: float
    session_wall_clock_minutes: int
    session_budget_usd: float
    fail_closed_sessions: int
    ci_fix_sessions_per_pr: int
    too_big_files: int
    too_big_lines: int


@dataclass(frozen=True)
class Schedule:
    no_new_sessions_after: time
    timezone: str


@dataclass(frozen=True)
class Models:
    default: str
    fable: str
    fable_label: str


@dataclass(frozen=True)
class Identities:
    github_login: str
    owner_plane_email: str
    worker_plane_email: str
    worker_github_login: str


@dataclass(frozen=True)
class GitHubAppConfig:
    app_id: int
    installation_id: int
    private_key: KeychainRef


@dataclass(frozen=True)
class PlaneConfig:
    url: str
    workspace: str
    api_key: KeychainRef
    client_cert: Path | None
    client_key: Path | None


@dataclass(frozen=True)
class ClaudeConfig:
    oauth_token: KeychainRef


@dataclass(frozen=True)
class Paths:
    repos: Path
    work: Path
    logs: Path
    snapshot: Path


@dataclass(frozen=True)
class Container:
    image: str
    network: str
    proxy: str


@dataclass(frozen=True)
class Config:
    paused: bool
    schedule: Schedule
    limits: Limits
    models: Models
    identities: Identities
    github_app: GitHubAppConfig
    plane: PlaneConfig
    claude: ClaudeConfig
    paths: Paths
    container: Container


@dataclass(frozen=True)
class ProjectConfig:
    identifier: str
    repo: str
    deploys: bool
    deploy_action: str = ""


def _keychain(d: dict) -> KeychainRef:
    return KeychainRef(service=d["service"], account=d["account"])


def _path(value: str | None) -> Path | None:
    return Path(value).expanduser() if value else None


def _time(value: str) -> time:
    hours, minutes = value.split(":")
    return time(int(hours), int(minutes))


def load_config(path: Path) -> Config:
    raw = yaml.safe_load(Path(path).read_text())
    return Config(
        paused=bool(raw["paused"]),
        schedule=Schedule(_time(raw["schedule"]["no_new_sessions_after"]), raw["schedule"]["timezone"]),
        limits=Limits(**raw["limits"]),
        models=Models(**raw["models"]),
        identities=Identities(**raw["identities"]),
        github_app=GitHubAppConfig(
            app_id=int(raw["github_app"]["app_id"]),
            installation_id=int(raw["github_app"]["installation_id"]),
            private_key=_keychain(raw["github_app"]["private_key"]),
        ),
        plane=PlaneConfig(
            url=raw["plane"]["url"].rstrip("/"),
            workspace=raw["plane"]["workspace"],
            api_key=_keychain(raw["plane"]["api_key"]),
            client_cert=_path(raw["plane"].get("client_cert")),
            client_key=_path(raw["plane"].get("client_key")),
        ),
        claude=ClaudeConfig(oauth_token=_keychain(raw["claude"]["oauth_token"])),
        paths=Paths(**{k: Path(v).expanduser() for k, v in raw["paths"].items()}),
        container=Container(**raw["container"]),
    )


def load_projects(path: Path) -> dict[str, ProjectConfig]:
    raw = yaml.safe_load(Path(path).read_text())["projects"]
    return {
        ident: ProjectConfig(ident, p["repo"], bool(p.get("deploys", False)), p.get("deploy_action", ""))
        for ident, p in raw.items()
    }
```

```python
from __future__ import annotations

import json
import re
from dataclasses import dataclass

LIMIT_TEXT = re.compile(r"hit your \w+ limit", re.IGNORECASE)


@dataclass(frozen=True)
class Window:
    utilization: float
    resets_at: int


@dataclass(frozen=True)
class RateLimit:
    status: str
    five_hour: Window | None
    seven_day: Window | None


def parse_stream_line(line: str) -> dict | None:
    line = line.strip()
    if not line:
        return None
    try:
        obj = json.loads(line)
    except json.JSONDecodeError:
        return None
    return obj if isinstance(obj, dict) else None


def _window(d: dict | None) -> Window | None:
    if not d or "utilization" not in d or "resetsAt" not in d:
        return None
    return Window(float(d["utilization"]), int(d["resetsAt"]))


def rate_limit_from_event(event: dict) -> RateLimit | None:
    if event.get("type") != "rate_limit_event":
        return None
    info = event.get("rate_limit_info") or {}
    windows = info.get("unifiedWindows") or {}
    return RateLimit(
        status=str(info.get("status", "unknown")),
        five_hour=_window(windows.get("five_hour")),
        seven_day=_window(windows.get("seven_day")),
    )


def result_hit_limit(result: dict) -> bool:
    return bool(result.get("is_error")) and bool(LIMIT_TEXT.search(str(result.get("result", ""))))
```

```python
from datetime import datetime, time
from zoneinfo import ZoneInfo

from bau.config import Limits, Schedule
from bau.policy import Decision, Policy, elapsed_fraction, pace_allows
from bau.telemetry import RateLimit, Window

LIMITS = Limits(50, 0.10, 0.80, 60, 5.0, 2, 3, 15, 400)
SCHEDULE = Schedule(time(5, 0), "Europe/London")
LONDON = ZoneInfo("Europe/London")
WEEK = 7 * 86400


def at(hour: int, minute: int = 0) -> datetime:
    return datetime(2026, 10, 15, hour, minute, tzinfo=LONDON)


def policy(now: datetime) -> Policy:
    return Policy(LIMITS, SCHEDULE, clock=lambda: now)


def rl(seven: float, five: float = 0.1, status: str = "allowed", resets_in: float = WEEK / 2) -> RateLimit:
    now = at(2).timestamp()
    return RateLimit(status, Window(five, int(now + 3600)), Window(seven, int(now + resets_in)))
```

```python
from __future__ import annotations

from collections.abc import Callable
from dataclasses import dataclass
from datetime import datetime

from bau.config import Limits, Schedule
from bau.telemetry import RateLimit, Window

WEEK_SECONDS = 7 * 86400


@dataclass(frozen=True)
class Decision:
    allowed: bool
    reason: str


OK = Decision(True, "ok")


def elapsed_fraction(resets_at: int, now: float, window_seconds: int = WEEK_SECONDS) -> float:
    remaining = (resets_at - now) / window_seconds
    return min(1.0, max(0.0, 1.0 - remaining))


def pace_allows(seven_day: Window | None, now: float, margin: float) -> Decision:
    if seven_day is None:
        return Decision(False, "telemetry-missing")
    if seven_day.utilization < elapsed_fraction(seven_day.resets_at, now) - margin:
        return OK
    return Decision(False, "pace")


class Policy:
    def __init__(self, limits: Limits, schedule: Schedule, clock: Callable[[], datetime]):
        self.limits = limits
        self.schedule = schedule
        self.clock = clock

    def can_start_session(
        self,
        *,
        latest: RateLimit | None,
        open_prs: int,
        sessions_started: int,
        paused: bool,
        new_ticket: bool,
    ) -> Decision:
        if paused:
            return Decision(False, "paused")
        if latest is not None and latest.status == "rejected":
            return Decision(False, "rejected")
        now = self.clock()
        if now.timetz().replace(tzinfo=None) >= self.schedule.no_new_sessions_after:
            return Decision(False, "cutoff")
        if latest is None or latest.seven_day is None or latest.five_hour is None:
            if sessions_started < self.limits.fail_closed_sessions:
                return Decision(True, "telemetry-missing")
            return Decision(False, "telemetry-missing")
        if latest.five_hour.utilization >= self.limits.five_hour_kill:
            return Decision(False, "five-hour")
        pace = pace_allows(latest.seven_day, now.timestamp(), self.limits.pace_margin)
        if not pace.allowed:
            return pace
        if new_ticket and open_prs >= self.limits.open_pr_ceiling:
            return Decision(False, "ceiling")
        return OK
```

Note `test_missing_telemetry_fails_closed_after_two_sessions` asserts `.allowed` is true for the first two sessions with reason `telemetry-missing`; the run loop uses the reason to mark the snapshot amber.

```python
from __future__ import annotations

import html
import re
import time
from dataclasses import dataclass, field
from pathlib import Path

import httpx

_TAG = re.compile(r"<[^>]+>")
_REF = re.compile(r"^\s*([A-Za-z0-9]+)-(\d+)\s*$")


@dataclass(frozen=True)
class Item:
    ref: str
    id: str
    project_id: str
    name: str
    description: str
    state: str
    labels: list[str]
    priority: str | None
    created_at: str
    assignees: list[str] = field(default_factory=list)


@dataclass(frozen=True)
class Comment:
    id: str
    author_email: str
    created_at: str
    text: str


def html_to_text(value: str | None) -> str:
    text = _TAG.sub("", (value or "").replace("</p>", "\n").replace("<br>", "\n").replace("<br/>", "\n"))
    return html.unescape(text).strip()


def markdown_to_html(md: str) -> str:
    out = []
    for para in md.strip().split("\n\n"):
        p = html.escape(para)
        p = re.sub(r"\*\*(.+?)\*\*", r"<strong>\1</strong>", p)
        p = re.sub(r"`(.+?)`", r"<code>\1</code>", p)
        out.append(f"<p>{p.replace(chr(10), '<br>')}</p>")
    return "".join(out)


def split_ref(ref: str) -> tuple[str, int]:
    m = _REF.match(ref or "")
    if not m:
        raise ValueError(f"Expected PROJECT-N, got {ref!r}")
    return m.group(1).upper(), int(m.group(2))


class PlaneClient:
    def __init__(
        self,
        url: str,
        workspace: str,
        api_key: str,
        cert: Path | None = None,
        key: Path | None = None,
        transport: httpx.BaseTransport | None = None,
    ):
        self.url = url.rstrip("/")
        self.workspace = workspace
        self._root = f"{self.url}/api/v1/workspaces/{workspace}"
        self._http = httpx.Client(
            cert=(str(cert), str(key)) if cert and key else None,
            headers={"X-API-Key": api_key, "Content-Type": "application/json"},
            timeout=30,
            transport=transport,
        )
        self._meta: dict[str, dict] = {}

    # ── transport ────────────────────────────────────────────────────────
    def _request(self, method: str, path: str, *, params: dict | None = None, json: dict | None = None):
        for attempt in range(5):
            r = self._http.request(method, self._root + path, params=params, json=json)
            if r.status_code == 429 or r.status_code >= 500:
                time.sleep(min(30, 2**attempt))
                continue
            if r.status_code >= 400:
                raise RuntimeError(f"Plane {method} {path} -> {r.status_code}: {r.text[:300]}")
            return r.json() if r.content.strip() else None
        raise RuntimeError(f"Plane {method} {path}: gave up after retries")

    def _get_all(self, path: str) -> list:
        params: dict = {"per_page": 1000}
        out: list = []
        while True:
            page = self._request("GET", path, params=params)
            if isinstance(page, list):
                return page
            out.extend(page.get("results", []))
            if not page.get("next_page_results"):
                return out
            params["cursor"] = page["next_cursor"]

    # ── lookups ──────────────────────────────────────────────────────────
    def _project(self, identifier: str) -> dict:
        if identifier not in self._meta:
            projects = {p["identifier"]: p for p in self._get_all("/projects/")}
            p = projects[identifier]
            pid = p["id"]
            self._meta[identifier] = {
                "project": p,
                "states": {s["name"].lower(): s["id"] for s in self._get_all(f"/projects/{pid}/states/")},
                "state_names": {s["id"]: s["name"] for s in self._get_all(f"/projects/{pid}/states/")},
                "labels": {l["name"]: l["id"] for l in self._get_all(f"/projects/{pid}/labels/")},
                "members": {m["id"]: m.get("email", "") for m in self._get_all(f"/projects/{pid}/members/")},
            }
        return self._meta[identifier]

    def _item(self, ref: str) -> tuple[dict, dict]:
        ident, seq = split_ref(ref)
        return self._project(ident), self._request("GET", f"/work-items/{ident}-{seq}/")

    def _format(self, ident: str, raw: dict) -> Item:
        meta = self._project(ident)
        label_names = {v: k for k, v in meta["labels"].items()}
        return Item(
            ref=f"{ident}-{raw['sequence_id']}",
            id=raw["id"],
            project_id=meta["project"]["id"],
            name=raw["name"],
            description=html_to_text(raw.get("description_html")),
            state=meta["state_names"].get(raw.get("state"), ""),
            labels=sorted(label_names.get(l, l) for l in raw.get("labels", [])),
            priority=raw.get("priority"),
            created_at=raw.get("created_at", ""),
            assignees=[meta["members"].get(a, a) for a in raw.get("assignees", [])],
        )

    # ── reads ────────────────────────────────────────────────────────────
    def list_items(self, identifier: str, label: str) -> list[Item]:
        meta = self._project(identifier)
        rows = self._get_all(f"/projects/{meta['project']['id']}/work-items/")
        items = [self._format(identifier, r) for r in rows]
        return [i for i in items if label in i.labels]

    def get_item(self, ref: str) -> Item:
        meta, raw = self._item(ref)
        return self._format(meta["project"]["identifier"], raw)

    def comments(self, ref: str) -> list[Comment]:
        meta, raw = self._item(ref)
        rows = self._get_all(f"/projects/{meta['project']['id']}/work-items/{raw['id']}/comments/")
        rows.sort(key=lambda c: c.get("created_at") or "")
        return [
            Comment(
                c["id"],
                meta["members"].get(c.get("actor") or c.get("created_by"), ""),
                c.get("created_at", ""),
                html_to_text(c.get("comment_html")),
            )
            for c in rows
        ]

    def project_url(self, ref: str) -> str:
        ident, seq = split_ref(ref)
        return f"{self.url}/{self.workspace}/browse/{ident}-{seq}/"

    # ── writes ───────────────────────────────────────────────────────────
    def _patch(self, ref: str, body: dict) -> None:
        meta, raw = self._item(ref)
        self._request("PATCH", f"/projects/{meta['project']['id']}/work-items/{raw['id']}/", json=body)

    def set_state(self, ref: str, state_name: str) -> None:
        meta, _ = self._item(ref)
        self._patch(ref, {"state": meta["states"][state_name.lower()]})

    def add_labels(self, ref: str, names: list[str]) -> None:
        meta, raw = self._item(ref)
        current = set(raw.get("labels", [])) | {meta["labels"][n] for n in names}
        self._patch(ref, {"labels": sorted(current)})

    def remove_labels(self, ref: str, names: list[str]) -> None:
        meta, raw = self._item(ref)
        current = set(raw.get("labels", [])) - {meta["labels"][n] for n in names if n in meta["labels"]}
        self._patch(ref, {"labels": sorted(current)})

    def assign(self, ref: str, email: str) -> None:
        meta, _ = self._item(ref)
        uid = next(k for k, v in meta["members"].items() if v == email)
        self._patch(ref, {"assignees": [uid]})

    def comment(self, ref: str, markdown: str) -> str:
        meta, raw = self._item(ref)
        c = self._request(
            "POST",
            f"/projects/{meta['project']['id']}/work-items/{raw['id']}/comments/",
            json={"comment_html": markdown_to_html(markdown)},
        )
        return c["id"]

    def link(self, ref: str, url: str, title: str) -> None:
        meta, raw = self._item(ref)
        self._request(
            "POST",
            f"/projects/{meta['project']['id']}/work-items/{raw['id']}/links/",
            json={"url": url, "title": title},
        )
```

```python
from __future__ import annotations

import base64
import shutil
import subprocess
from pathlib import Path


def _auth_args(token: str) -> list[str]:
    if not token:
        return []
    basic = base64.b64encode(f"x-access-token:{token}".encode()).decode()
    return ["-c", f"http.extraheader=AUTHORIZATION: basic {basic}"]


class Repos:
    def __init__(self, repos_root: Path, work_root: Path):
        self.repos_root = Path(repos_root)
        self.work_root = Path(work_root)
        self.repos_root.mkdir(parents=True, exist_ok=True)
        self.work_root.mkdir(parents=True, exist_ok=True)

    @staticmethod
    def _git(
        *args: str, cwd: Path | None = None, token: str = "", check: bool = True
    ) -> subprocess.CompletedProcess:
        return subprocess.run(
            ["git", *_auth_args(token), *args], cwd=cwd, check=check, capture_output=True, text=True
        )

    def bare_path(self, repo: str) -> Path:
        return self.repos_root / f"{repo.split('/', 1)[1]}.git"

    def checkout_path(self, branch: str) -> Path:
        return self.work_root / branch

    def ensure_bare(self, repo: str, token: str, origin_url: str | None = None) -> Path:
        bare = self.bare_path(repo)
        url = origin_url or f"https://github.com/{repo}.git"
        if not (bare / "HEAD").exists():
            self._git("clone", "--bare", url, str(bare), token=token)
            self._git("config", "remote.origin.fetch", "+refs/heads/*:refs/heads/*", cwd=bare)
        return bare

    def fetch(self, repo: str, token: str) -> None:
        self._git("fetch", "--prune", "origin", cwd=self.bare_path(repo), token=token)

    def create_checkout(self, repo: str, branch: str) -> Path:
        bare = self.bare_path(repo)
        dest = self.checkout_path(branch)
        origin = self._git("remote", "get-url", "origin", cwd=bare).stdout.strip()
        self._git("clone", "--reference", str(bare), "--branch", "main", str(bare), str(dest))
        self._git("remote", "set-url", "origin", origin, cwd=dest)
        self._git("checkout", "-b", branch, cwd=dest)
        return dest

    def delete_checkout(self, branch: str) -> None:
        shutil.rmtree(self.checkout_path(branch), ignore_errors=True)

    def rebase_onto_main(self, branch: str, token: str) -> bool:
        wt = self.checkout_path(branch)
        self._git("fetch", "origin", "main", cwd=wt, token=token)
        result = self._git("rebase", "origin/main", cwd=wt, check=False)
        if result.returncode != 0:
            self._git("rebase", "--abort", cwd=wt, check=False)
            return False
        return True

    def diff_stats(self, branch: str) -> tuple[int, int]:
        wt = self.checkout_path(branch)
        out = self._git("diff", "--numstat", "origin/main...HEAD", cwd=wt).stdout.strip().splitlines()
        files = len(out)
        lines = 0
        for row in out:
            added, deleted, _ = row.split("\t", 2)
            lines += (int(added) if added.isdigit() else 0) + (int(deleted) if deleted.isdigit() else 0)
        return files, lines
```

```python
    return f"<<<{title} (untrusted data)\n{body.strip()}\n>>>\n"


def build_brief(
    item: Item, repo: str, branch: str, feedback: Feedback | None, ci_log: str | None, limits: Limits

    parts.append(
        f"=== TICKET ===\nRepository: {repo}\nBranch: {branch}\nRef: {item.ref}\n"
        f"Size limit: {limits.too_big_files} files or {limits.too_big_lines} changed lines\n"
    )

            f"TICKET {item.ref}",
            f"Title: {item.name}\nLabels: {', '.join(item.labels)}\n\n{item.description}",
        )
    )
    if feedback:
        if feedback.conflict:
            parts.append(
                "The branch conflicts with main. Rebase onto origin/main and resolve the conflicts first.\n"
            )

            parts.append(_block("CI LOG", ci_log[-6000:]))

                    f"{c.text}\n\nAck marker to include: {ack_marker(c.id)}",

            )
```

```python
from __future__ import annotations

import os
import subprocess
import tempfile
import threading
import time
from dataclasses import dataclass
from pathlib import Path

from bau.config import Config
from bau.outcome import too_big_reason
from bau.telemetry import RateLimit, parse_stream_line, rate_limit_from_event, result_hit_limit


@dataclass(frozen=True)
class SessionResult:
    outcome: str
    reason: str = ""
    latest: RateLimit | None = None
    cost_usd: float = 0.0
    result_text: str = ""


def docker_command(
    cfg: Config,
    *,
    name: str,
    checkout: Path,
    bare: Path,
    model: str,
    budget: float,
    env_file: str | None = None,
) -> list[str]:
    cmd = [
        "docker",
        "run",
        "--rm",
        "-i",
        "--name",
        name,
        "--network",
        cfg.container.network,
        "-v",
        f"{bare}:{bare}:ro",
        "-v",
        f"{checkout}:{checkout}",
        "-w",
        str(checkout),
        "-e",
        f"HTTPS_PROXY={cfg.container.proxy}",
        "-e",
        f"HTTP_PROXY={cfg.container.proxy}",
    ]
    if env_file:
        cmd += ["--env-file", env_file]
    cmd += [
        cfg.container.image,
        "claude",
        "-p",
        "--output-format",
        "stream-json",
        "--verbose",
        "--model",
        model,
        "--max-budget-usd",
        str(budget),
        "--dangerously-skip-permissions",
    ]
    return cmd


class SessionRunner:
    def __init__(self, cfg: Config):
        self.cfg = cfg
        self.wall_clock_seconds = cfg.limits.session_wall_clock_minutes * 60

    def _kill(self, name: str) -> None:
        subprocess.run(["docker", "kill", name], capture_output=True)

    def run(
        self,
        *,
        name: str,
        checkout: Path,
        bare: Path,
        brief: str,
        model: str,
        github_token: str,
        oauth_token: str,
        log_path: Path,
    ) -> SessionResult:
        log_path.parent.mkdir(parents=True, exist_ok=True)
        fd, env_file = tempfile.mkstemp(prefix="bau-env-")
        try:
            with os.fdopen(fd, "w") as f:
                f.write(
                    f"GH_TOKEN={github_token}\nGITHUB_TOKEN={github_token}\n"
                    f"CLAUDE_CODE_OAUTH_TOKEN={oauth_token}\n"
                )
            os.chmod(env_file, 0o600)
            cmd = docker_command(
                self.cfg,
                name=name,
                checkout=checkout,
                bare=bare,
                model=model,
                budget=self.cfg.limits.session_budget_usd,
                env_file=env_file,
            )
            proc = subprocess.Popen(
                cmd, stdin=subprocess.PIPE, stdout=subprocess.PIPE, stderr=subprocess.STDOUT, text=True
            )
            assert proc.stdin and proc.stdout
            proc.stdin.write(brief)
            proc.stdin.close()

            latest: RateLimit | None = None
            result: dict | None = None
            killed = ""
            started = time.monotonic()

            def watchdog():
                while proc.poll() is None:
                    if time.monotonic() - started > self.wall_clock_seconds:
                        nonlocal killed
                        killed = killed or "killed_wall_clock"
                        self._kill(name)
                        proc.kill()
                        return
                    time.sleep(0.2)

            threading.Thread(target=watchdog, daemon=True).start()
            with open(log_path, "a") as log:
                for line in proc.stdout:
                    log.write(line)
                    obj = parse_stream_line(line)
                    if not obj:
                        continue
                    rl = rate_limit_from_event(obj)
                    if rl:
                        latest = rl
                        if rl.status == "rejected":
                            killed = killed or "rate_limited"
                            self._kill(name)
                            proc.kill()
                            break
                        if rl.five_hour and rl.five_hour.utilization >= self.cfg.limits.five_hour_kill:
                            killed = killed or "killed_five_hour"
                            self._kill(name)
                            proc.kill()
                            break
                    if obj.get("type") == "result":
                        result = obj
            code = proc.wait()
        finally:
            os.unlink(env_file)

        if killed:
            return SessionResult(killed, "", latest)
        if result is None:
            return SessionResult("failed", f"no result line, exit {code}", latest)
        text = str(result.get("result", ""))
        cost = float(result.get("total_cost_usd") or 0.0)
        if result_hit_limit(result):
            return SessionResult("rate_limited", text, latest, cost, text)
        if result.get("is_error"):
            return SessionResult("failed", text[:300], latest, cost, text)
        reason = too_big_reason(text)
        if reason:
            return SessionResult("too_big", reason, latest, cost, text)
        if code != 0:
            return SessionResult("failed", f"exit {code}", latest, cost, text)
        return SessionResult("done", "", latest, cost, text)
```

The `crash` fake exits 3 without a result line, so `failed` with `exit 3` comes from the `result is None` branch; keep the message `f"no result line, exit {code}"` so the test's `"exit 3" in r.reason` holds.

```python
from __future__ import annotations

import json
import os
import tempfile
from dataclasses import asdict, dataclass
from datetime import UTC, datetime
from pathlib import Path

from bau.policy import elapsed_fraction
from bau.telemetry import RateLimit


@dataclass(frozen=True)
class OpenPrRow:
    repo: str
    ref: str
    title: str
    url: str
    opened: str
    age_days: int
    ci: str
    draft: bool
    unresolved_comments: int
    plane_url: str


@dataclass(frozen=True)
class DeployRow:
    repo: str
    ref: str
    title: str
    pr_url: str
    merged_at: str
    action: str


@dataclass(frozen=True)
class LastRun:
    started: str
    ended: str
    sessions: int
    prs_opened: int
    feedback_handled: int
    stop_reason: str
    telemetry: str


def build_snapshot(
    *,
    paused: bool,
    last_run: LastRun | None,
    latest: RateLimit | None,
    open_prs: list[OpenPrRow],
    deploy_pending: list[DeployRow],
    declined: list[dict],
    now: float,
) -> dict:
    pace = None
    if latest and latest.five_hour and latest.seven_day:
        pace = {
            "five_hour_used": latest.five_hour.utilization,
            "five_hour_resets": latest.five_hour.resets_at,
            "seven_day_used": latest.seven_day.utilization,
            "seven_day_resets": latest.seven_day.resets_at,
            "elapsed_pct": round(elapsed_fraction(latest.seven_day.resets_at, now), 3),
        }
    return {
        "schema": 1,
        "generated_at": datetime.fromtimestamp(now, UTC).isoformat().replace("+00:00", "Z"),
        "paused": paused,
        "last_run": asdict(last_run) if last_run else None,
        "pace": pace,
        "open_prs": [asdict(r) for r in open_prs],
        "deploy_pending": [asdict(r) for r in deploy_pending],
        "declined": declined,
    }


def write_snapshot(path: Path, data: dict) -> None:
    path = Path(path)
    path.parent.mkdir(parents=True, exist_ok=True)
```

```python
from __future__ import annotations

import re
import subprocess
from collections.abc import Callable
from dataclasses import dataclass, field
from datetime import UTC, datetime
from pathlib import Path

from bau.checkout import Repos
from bau.config import Config, Models, ProjectConfig
from bau.feedback import Feedback, ack_marker, pending_plane_comments, pending_threads
from bau.github import PR, GitHubApp, GitHubClient
from bau.outcome import diff_too_big

from bau.prompts import build_brief

from bau.telemetry import RateLimit, parse_stream_line, rate_limit_from_event

PICKED = re.compile(r"\[bau:picked-up from=([^\]]+)\]")
REPO_LINE = re.compile(r"^repo:\s*([\w.-]+/[\w.-]+)\s*$", re.MULTILINE)
REF_IN_BODY = re.compile(r"Plane:\s*([A-Z0-9]+-\d+)")


def branch_name(ref: str, title: str) -> str:
    slug = re.sub(r"[^a-z0-9]+", "-", title.lower()).strip("-")[:40].rstrip("-")
    return f"{ref.lower()}-{slug}"


def repo_for(item: Item, projects: dict[str, ProjectConfig]) -> str | None:
    m = REPO_LINE.search(item.description or "")
    if m:
        return m.group(1)
    ident, _ = split_ref(item.ref)
    p = projects.get(ident)
    return p.repo if p else None


def model_for(item: Item, models: Models) -> str:
    return models.fable if models.fable_label in item.labels else models.default


def previous_state(comments: list[Comment]) -> str | None:
    for c in reversed(comments):
        m = PICKED.search(c.text)
        if m:
            return m.group(1).strip()
    return None


@dataclass
class NightReport:
    stop_reason: str = "ok"
    sessions: int = 0
    prs_opened: int = 0
    feedback_handled: int = 0
    declined: list[dict] = field(default_factory=list)
    latest: RateLimit | None = None
    telemetry: str = "ok"
    planned: list[str] = field(default_factory=list)


class Night:
    def __init__(
        self,
        cfg: Config,
        projects: dict[str, ProjectConfig],
        plane: PlaneClient,
        gh_app: GitHubApp,
        github_factory: Callable[[str], GitHubClient],
        repos: Repos,
        runner: SessionRunner,
        clock: Callable[[], datetime],
        *,
        oauth_token: str,
        dry_run: bool = False,
        log: Callable[..., None] = print,
    ):
        self.cfg, self.projects, self.plane, self.gh_app = cfg, projects, plane, gh_app
        self.github_factory, self.repos, self.runner, self.clock = github_factory, repos, runner, clock
        self.oauth_token, self.dry_run, self.log = oauth_token, dry_run, log
        self.policy = Policy(cfg.limits, cfg.schedule, clock)
        self.report = NightReport()
        self._tokens: dict[str, str] = {}
        self._fix_counts: dict[int, int] = {}

    # ── helpers ───────────────────────────────────────────────────────────
    def token(self, repo: str) -> str:
        if repo not in self._tokens:
            self._tokens[repo] = self.gh_app.installation_token(repo).value
        return self._tokens[repo]

    def now_iso(self) -> str:
        return self.clock().astimezone(UTC).isoformat().replace("+00:00", "Z")

    def probe(self) -> RateLimit | None:
        """One-line session to read the current usage windows."""
        cmd = [
            "claude",
            "-p",
            "Reply with exactly: ok",
            "--output-format",
            "stream-json",
            "--verbose",
            "--model",
            "claude-haiku-5-5",
            "--max-budget-usd",
            "0.05",
            "--disable-slash-commands",
        ]
        proc = subprocess.run(
            cmd,
            input="",
            capture_output=True,
            text=True,
            env={
                "CLAUDE_CODE_OAUTH_TOKEN": self.oauth_token,
                "PATH": "/opt/homebrew/bin:/usr/bin:/bin",
                "HOME": str(Path.home()),
            },
            timeout=120,
        )
        latest = None
        for line in proc.stdout.splitlines():
            obj = parse_stream_line(line)
            if obj and (rl := rate_limit_from_event(obj)):
                latest = rl
        return latest

    def decline(self, item: Item, reason: str) -> None:
        self.report.declined.append({"ref": item.ref, "reason": reason, "at": self.now_iso()})
        self.log(f"decline {item.ref}: {reason}")
        if not self.dry_run:
            self.plane.comment(item.ref, f"[bau] Not picked up: {reason}")

    def may_start(self, *, new_ticket: bool) -> bool:
        d = self.policy.can_start_session(
            latest=self.report.latest,
            open_prs=self._open_total,
            sessions_started=self.report.sessions,
            paused=self.cfg.paused,
            new_ticket=new_ticket,
        )
        if d.reason == "telemetry-missing":
            self.report.telemetry = "missing"
        if not d.allowed:
            self.report.stop_reason = d.reason
        return d.allowed

    def session(self, *, item: Item, repo: str, branch: str, brief: str, model: str) -> SessionResult:
        self.report.sessions += 1
        result = self.runner.run(
            name=f"bau-{item.ref.lower()}",
            checkout=self.repos.checkout_path(branch),
            bare=self.repos.bare_path(repo),
            brief=brief,
            model=model,
            github_token=self.token(repo),
            oauth_token=self.oauth_token,
            log_path=self.cfg.paths.logs / f"{self.clock():%Y-%m-%d}-{item.ref}.log",
        )
        if result.latest:
            self.report.latest = result.latest
        if result.outcome == "rate_limited":
            self.report.stop_reason = "rejected"
        return result

    # ── passes ────────────────────────────────────────────────────────────
    def run(self) -> NightReport:
        self.report.latest = self.probe()
        if self.report.latest is None:
            self.report.telemetry = "missing"
        self.log(f"preflight: latest={self.report.latest}")
        repos = {p.repo for p in self.projects.values()}
        self._open: dict[str, list[PR]] = {}
        for repo in sorted(repos):
            gh = self.github_factory(repo)
            self._open[repo] = gh.open_prs(repo, self.cfg.identities.worker_github_login)
            if not self.dry_run:
                self.repos.ensure_bare(repo, self.token(repo))
                self.repos.fetch(repo, self.token(repo))
        self._open_total = sum(len(v) for v in self._open.values())
        if not self.may_start(new_ticket=False):
            return self.report
        self.feedback_pass()
        self.merge_pass()
        self.new_tickets_pass()
        return self.report

    def feedback_pass(self) -> None:
        for repo, prs in self._open.items():
            gh = self.github_factory(repo)
            for pr in sorted(prs, key=lambda p: p.created_at):
                ref = (
                    (REF_IN_BODY.search(pr.body) or REF_IN_BODY.search(pr.title) or [None, None])[1]
                    if isinstance(REF_IN_BODY.search(pr.body) or REF_IN_BODY.search(pr.title), re.Match)
                    else None
                )
                m = REF_IN_BODY.search(pr.body) or re.search(r"\(([A-Z0-9]+-\d+)\)", pr.title)
                if not m:
                    continue
                ref = m.group(1)
                threads = pending_threads(
                    gh.review_threads(repo, pr.number),
                    self.cfg.identities.github_login,
                    self.cfg.identities.worker_github_login,
                )
                plane_comments = pending_plane_comments(
                    self.plane.comments(ref),
                    self.cfg.identities.owner_plane_email,
                    self.cfg.identities.worker_plane_email,
                )
                ci = gh.ci_status(repo, pr.head_sha)
                ci_red = (
                    ci == "red"
                    and self._fix_counts.get(pr.number, 0) < self.cfg.limits.ci_fix_sessions_per_pr
                )
                fb = Feedback(threads, plane_comments, conflict=pr.mergeable_state == "dirty", ci_red=ci_red)
                if fb.empty:
                    continue
                if self.dry_run:
                    self.report.planned.append(f"feedback {ref} -> {repo} PR #{pr.number}")
                    continue
                if not self.may_start(new_ticket=False):
                    return
                item = self.plane.get_item(ref)
                if not fb.conflict:
                    self.repos.rebase_onto_main(pr.head_ref, self.token(repo))
                brief = build_brief(item, repo, pr.head_ref, fb, None, self.cfg.limits)
                result = self.session(
                    item=item,
                    repo=repo,
                    branch=pr.head_ref,
                    brief=brief,
                    model=model_for(item, self.cfg.models),
                )
                if ci_red:
                    self._fix_counts[pr.number] = self._fix_counts.get(pr.number, 0) + 1
                if result.outcome == "done":
                    self.report.feedback_handled += 1
                    for c in plane_comments:
                        self.plane.comment(ref, f"[bau] Addressed in PR #{pr.number}. {ack_marker(c.id)}")
                elif result.outcome == "rate_limited":
                    return
                else:
                    gh.comment(
                        repo,
                        pr.number,
                        f"[bau] Feedback session ended with {result.outcome}: {result.reason}",
                    )

    def merge_pass(self) -> None:
        for repo in self._open:
            gh = self.github_factory(repo)
            since = (self.clock().astimezone(UTC)).strftime("%Y-%m-%dT00:00:00Z")
            for pr in gh.merged_prs_since(
                repo, self.cfg.identities.worker_github_login, since[:4] + "-01-01T00:00:00Z"
            ):
                m = REF_IN_BODY.search(pr.body) or re.search(r"\(([A-Z0-9]+-\d+)\)", pr.title)
                if not m:
                    continue
                ref = m.group(1)
                item = self.plane.get_item(ref)
                if item.state in ("Ready for test", "Done"):
                    continue
                if self.dry_run:
                    self.report.planned.append(f"merged {ref} -> close loop")
                    continue
                ident, _ = split_ref(ref)
                project = self.projects.get(ident)
                target = "Ready for test" if project and project.deploys else "Done"
                self.plane.set_state(ref, target)
                self.plane.comment(ref, f"[bau] PR #{pr.number} merged at {pr.merged_at}; moved to {target}.")
                self.repos.delete_checkout(pr.head_ref)

    def new_tickets_pass(self) -> None:
        candidates: list[Item] = []
        for ident in self.projects:
            candidates += self.plane.list_items(ident, "BAU")
        open_refs = {
            m.group(1)
            for prs in self._open.values()
            for p in prs
            if (m := REF_IN_BODY.search(p.body) or re.search(r"\(([A-Z0-9]+-\d+)\)", p.title))
        }
        order = {"urgent": 0, "high": 1, "medium": 2, "low": 3, None: 4, "none": 4}
        for item in sorted(candidates, key=lambda i: (order.get(i.priority, 4), i.created_at)):
            if "blocked" in item.labels or item.ref in open_refs:
                continue
            repo = repo_for(item, self.projects)
            if not repo:
                self.decline(item, "no repository mapped for this project; add it to projects.yaml")
                continue
            if not item.description.strip():
                self.decline(item, "ticket has no description; BAU needs one to work from")
                continue
            gh = self.github_factory(repo)
            if not gh.branch_protected(repo):
                self.decline(item, f"{repo} has no branch protection on main; BAU refuses to work there")
                continue
            model = model_for(item, self.cfg.models)
            if self.dry_run:
                self.report.planned.append(f"new-ticket {item.ref} -> {repo} ({model})")
                continue
            if not self.may_start(new_ticket=True):
                return
            self.work_new_ticket(item, repo, gh, model)
            if self.report.stop_reason != "ok":
                return

    def work_new_ticket(self, item: Item, repo: str, gh: GitHubClient, model: str) -> None:
        branch = branch_name(item.ref, item.name)
        self.plane.set_state(item.ref, "In progress")
        self.plane.assign(item.ref, self.cfg.identities.worker_plane_email)
        self.plane.comment(
            item.ref, f"[bau:picked-up from={item.state}] Working on branch `{branch}` in {repo}."
        )
        self.repos.create_checkout(repo, branch)
        brief = build_brief(item, repo, branch, None, None, self.cfg.limits)
        result = self.session(item=item, repo=repo, branch=branch, brief=brief, model=model)
        if hasattr(gh, "after_session"):
            gh.after_session()  # test hook: the fake GitHub learns about the PR the fake agent "opened"
        if result.outcome == "too_big":
            self.plane.set_state(item.ref, item.state)
            self.plane.comment(item.ref, f"[bau] Too big for BAU: {result.reason}. Returned to {item.state}.")
            self.repos.delete_checkout(branch)
            return
        if result.outcome != "done":
            self.plane.comment(item.ref, f"[bau] Session ended with {result.outcome}: {result.reason}")
            return
        opened = next(
            (p for p in gh.open_prs(repo, self.cfg.identities.worker_github_login) if p.head_ref == branch),
            None,
        )
        if not opened:
            self.plane.comment(item.ref, "[bau] Session finished but no PR was opened; see the log.")
            return
        files, lines = self.repos.diff_stats(branch)
        if diff_too_big(files, lines, self.cfg.limits):
            gh.comment(
                repo,
                opened.number,
                f"[bau] Closing: {files} files / {lines} lines exceeds the BAU size limit.",
            )
            gh.close_pr(repo, opened.number)
            self.plane.set_state(item.ref, item.state)
            self.plane.comment(
                item.ref, f"[bau] Too big for BAU ({files} files, {lines} lines). Returned to {item.state}."
            )
            self.repos.delete_checkout(branch)
            return
        self.report.prs_opened += 1
        self._open_total += 1
        self.plane.link(item.ref, opened.url, f"PR #{opened.number}")
        ci = gh.ci_status(repo, opened.head_sha)
        if ci == "green":
            gh.mark_ready(opened.node_id)
            self.plane.comment(item.ref, f"[bau] PR #{opened.number} opened and CI is green: {opened.url}")
        else:
            self.plane.comment(
                item.ref, f"[bau] PR #{opened.number} opened as draft; CI is {ci}: {opened.url}"
            )
```

```python
from __future__ import annotations

import subprocess

from bau.config import KeychainRef


def read_secret(ref: KeychainRef, runner=subprocess.run) -> str:
    r = runner(
        ["security", "find-generic-password", "-s", ref.service, "-a", ref.account, "-w"],
        capture_output=True,
        text=True,
    )
    if r.returncode != 0:
        raise RuntimeError(f"keychain item {ref.service}/{ref.account} not found")
    return r.stdout.strip()
```

```python
# bau/cli.py
from __future__ import annotations

import argparse
import sys
import time
from datetime import datetime
from pathlib import Path

from bau.checkout import Repos
from bau.config import Config, load_config, load_projects

DEFAULT_CONFIG = Path("/Users/nakomis/bau/src/config")


def build_parser() -> argparse.ArgumentParser:
    p = argparse.ArgumentParser(prog="bau")
    p.add_argument("--config", type=Path, default=DEFAULT_CONFIG)
    sub = p.add_subparsers(dest="command", required=True)
    run = sub.add_parser("run", help="the nightly run")
    run.add_argument("--dry-run", action="store_true")
    sub.add_parser("snapshot", help="refresh state.json without starting sessions")
    sub.add_parser("probe", help="print the current usage windows")
    return p


def wire(cfg: Config, config_dir: Path):
    projects = load_projects(config_dir / "projects.yaml")
    plane = PlaneClient(
        cfg.plane.url,
        cfg.plane.workspace,
        read_secret(cfg.plane.api_key),
        cfg.plane.client_cert,
        cfg.plane.client_key,
    )
    app = GitHubApp(
        cfg.github_app.app_id, read_secret(cfg.github_app.private_key), cfg.github_app.installation_id
    )
    clients: dict[str, GitHubClient] = {}

    def factory(repo: str) -> GitHubClient:
        if repo not in clients:
            clients[repo] = GitHubClient(app.installation_token(repo).value)
        return clients[repo]

    repos = Repos(cfg.paths.repos, cfg.paths.work)
    clock = lambda: datetime.now(ZoneInfo(cfg.schedule.timezone))  # noqa: E731
    return projects, plane, app, factory, repos, clock


def snapshot_rows(cfg: Config, projects, plane, factory, clock):
    open_rows, deploy_rows = [], []
    now = clock()
    for ident, project in projects.items():
        gh = factory(project.repo)
        for pr in gh.open_prs(project.repo, cfg.identities.worker_github_login):
            ref = Night.ref_of(pr)
            if not ref:
                continue
            threads = gh.review_threads(project.repo, pr.number)
            unresolved = sum(1 for t in threads if not t.resolved)
            opened = datetime.fromisoformat(pr.created_at.replace("Z", "+00:00"))
            open_rows.append(
                OpenPrRow(
                    project.repo,
                    ref,
                    pr.title,
                    pr.url,
                    pr.created_at,
                    (now - opened).days,
                    gh.ci_status(project.repo, pr.head_sha),
                    pr.draft,
                    unresolved,
                    plane.project_url(ref),
                )
            )
        if project.deploys:
            for item in plane.list_items(ident, "BAU"):
                if item.state == "Ready for test":
                    deploy_rows.append(
                        DeployRow(project.repo, item.ref, item.name, "", "", project.deploy_action)
                    )
    return open_rows, deploy_rows


def main(argv: list[str] | None = None) -> int:
    args = build_parser().parse_args(argv)
    cfg = load_config(args.config / "bau.yaml")
    projects, plane, app, factory, repos, clock = wire(cfg, args.config)
    oauth = read_secret(cfg.claude.oauth_token)
    if args.command == "probe":
        night = Night(cfg, projects, plane, app, factory, repos, SessionRunner(cfg), clock, oauth_token=oauth)
        print(night.probe())
        return 0
    if args.command == "run":
        started = clock()
        night = Night(
            cfg,
            projects,
            plane,
            app,
            factory,
            repos,
            SessionRunner(cfg),
            clock,
            oauth_token=oauth,
            dry_run=args.dry_run,
        )
        report = night.run()
        if args.dry_run:
            print("\n".join(report.planned) or "nothing to do")
            return 0
        last = LastRun(
            started.isoformat(),
            clock().isoformat(),
            report.sessions,
            report.prs_opened,
            report.feedback_handled,
            report.stop_reason,
            report.telemetry,
        )
        open_rows, deploy_rows = snapshot_rows(cfg, projects, plane, factory, clock)
        write_snapshot(
            cfg.paths.snapshot,
            build_snapshot(
                paused=cfg.paused,
                last_run=last,
                latest=report.latest,
                open_prs=open_rows,
                deploy_pending=deploy_rows,
                declined=report.declined,
                now=time.time(),
            ),
        )
        return 0 if report.stop_reason in ("ok", "cutoff", "pace", "ceiling") else 1
    if args.command == "snapshot":
        from bau.snapshot import read_snapshot

        previous = read_snapshot(cfg.paths.snapshot) or {}
        open_rows, deploy_rows = snapshot_rows(cfg, projects, plane, factory, clock)
        last = LastRun(**previous["last_run"]) if previous.get("last_run") else None
        write_snapshot(
            cfg.paths.snapshot,
            build_snapshot(
                paused=cfg.paused,
                last_run=last,
                latest=None,
                open_prs=open_rows,
                deploy_pending=deploy_rows,
                declined=previous.get("declined", []),
                now=time.time(),
            ),
        )
        return 0
    return 2


if __name__ == "__main__":
    sys.exit(main())
```
